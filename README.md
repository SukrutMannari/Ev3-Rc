# Ev3-Rc
The goal of this project was to build a remote-controlled car using a LEGO EV3 brain and program it to drive using a Bluetooth gaming controller. I also wanted to add cool features like working headlights and custom sound effects.
Motor Ports: 2 large motors on port A & B
Steering motor (medium motor) on port c.
Color sensor on port A.
This project should work with any generic X-Box controller with analog triggers. 
The motors are reversed so you can gear up because 2 motors have too much unnecessary torque.

The ev3 needs EV3.dev installed and you also need an ide with the ev3.dev extension.
